# ECHO HUD

CS2 yayın paneli.

**İndir:** [ECHO HUD Kurulum (son sürüm)](https://github.com/ecrp-maker/echo-hud/releases/latest/download/ECHO.HUD.Setup.exe)

Kurulumdan sonra panelde **Lisans gir** penceresindeki PC kodunu satıcıya gönder; sana özel lisansı aynı pencereye yapıştır. Program güncellemeleri panelden kendiliğinden alır.
